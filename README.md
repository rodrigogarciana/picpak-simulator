# PicPak Simulator

A static PicPak preview page that mimics the 4-color PicPak screen from the Kickstarter project.

The goal is to help users preview and adjust images before sending them to the PicPak. This is a work in progress: it does not fully mimic the real device yet, but it tries to get close enough to be useful.

## Development

This project is intended to stay simple and static. The page to serve is `index.html`, with any supporting CSS or JavaScript kept nearby.

## GitHub Pages

The repository is public and can be served with GitHub Pages from the `master` branch. Since the entry page is `index.html`, the published site will open directly at the repository Pages URL.
